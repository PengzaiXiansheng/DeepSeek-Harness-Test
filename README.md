# DeepSeek-Harness-Test

Test repository for **dsh-superagent**.

## Purpose

This repository exercises the dsh-superagent prototype: a person opens an issue or
comments `@<agent login> <request>`, the agent assesses it under its Policy, works in
its own Session and branch, and delivers a pull request.

## Notes

- Work arrives through the agent account's GitHub notifications.
- Proposals stay in observe mode until the operator widens the rules.
